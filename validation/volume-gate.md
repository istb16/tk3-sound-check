## 4. 捕まえられないもの: 声の下の BGM

音源が入れ替わるわけではないので形は変わらない。**それでいてレベルは上がる**ので、
フェーダーに触れていないのに差が出る。スペクトル照合では捕まらない。

| BGM のレベル（声比） | 形の距離[dB] | 表示に出る誤差[dB] |
|---|---|---|
| -15 dB | 1.74 | **-0.25** |
| -10 dB | 2.93 | **-0.26** |
| -6 dB | 4.29 | **-0.80** |
| -3 dB | 5.24 | **-1.03** |
| 0 dB | 5.96 | **0.31** |

**通す範囲に残る誤差は 1dB 以下に収まっている。** 声より 3dB 下まで BGM が
上がると距離がしきい値を超えるので、そこから先は画面が黙る——形の照合は
BGM を狙って作ったものではないが、結果として「誤差が効き始めるあたり」で
引っかかっている。

ただし**これは合成のピンクノイズでの話である**。実際の音楽が声とどれだけ
違う形をしているかはここでは測れていない。声に近い形の BGM（弦や男声の
コーラス）なら距離は伸びず、1dB 前後の誤差が断りなしに出る。
